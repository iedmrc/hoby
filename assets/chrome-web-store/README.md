# Store asset provenance

All screenshots use an isolated browser-preview workspace with fictional data from `demo-workspace.json`. URLs use `example.com`; the preview's built-in open-tab samples are synthetic. No personal workspace, browsing history, account page, or browser chrome is included.

The screenshots are actual Hoby UI captures at 1280×800, not generated representations of product behavior. The submitted listing uses `01-workspace.png` through `04-local-backup.png`. `05-collections.png` is an additional prepared screenshot.

`small-promo.svg` and `marquee.svg` are editable, code-native artwork using Hoby's existing visual identity. Their PNG exports are 440×280 and 1400×560 respectively. The store icon comes from `public/icons/icon-128.png`.

For future screenshots, use a fresh isolated preview, import only the fictional fixture, and inspect every image before uploading it. Capture page content only. Never import or capture a real user's workspace, and never use a signed-in account/dashboard screenshot as a promotional asset.
