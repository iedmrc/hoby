# Security policy

## Supported versions

Security fixes are made against the latest code on `main` and shipped in the next Chrome Web Store release. Only the latest published version is supported; older releases, commits, and development builds are not supported separately.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue or discussion.

Once the public repository has private vulnerability reporting enabled, use [Report a vulnerability](https://github.com/iedmrc/hoby/security/advisories/new). If that option is unavailable, do not open a public issue; contact the maintainer through an available private contact method on the [maintainer's GitHub profile](https://github.com/iedmrc).

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Remove personal browsing data, tokens, and private URLs from screenshots or logs.

Hoby has no backend and does not intentionally transmit saved tab data. Reports involving unexpected network access, permission expansion, data loss, script injection, or exposure of stored URLs are especially important.
